# card

Личный сайт-визитка. Сейчас готов только первый экран в двух вариантах — чтобы выбрать стиль.
Остальной сайт строится после выбора.

| Адрес | Что там |
| --- | --- |
| `/`, `/ru/` | временная страница выбора со ссылками на оба варианта |
| `/a/`, `/ru/a/` | вариант А: карточка-бейдж с голографической фольгой, на обороте QR-код |
| `/b/`, `/ru/b/` | вариант Б: крупная живая типографика, без карточки |

Английский — по умолчанию, русский — в `/ru/`. Обе языковые версии собираются из одного шаблона.

## Где что менять

| Что | Файл |
| --- | --- |
| Имя, строка о деле, ники Telegram и Instagram | `src/data/profile.ts` |
| Адрес сайта (от него зависят QR-код, ссылки и базовый путь) | `site.config.mjs` |
| Подписи на кнопках и подсказки | `src/data/ui.ts` |

Имя и ники настоящие. Адрес сайта в `site.config.mjs` пока временный (`https://example.com/`):
его нужно заменить, когда появится хостинг.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

Готовый сайт появляется в папке `dist/` — это обычные файлы, их можно выложить на любой хостинг.

## Как устроено

- Astro, статическая сборка. Без видео, WebGL, canvas и сторонних библиотек в браузере.
- Движение — CSS и около 3 КБ своего кода (`src/scripts/motion.ts`): гироскоп телефона, курсор
  или палец; если ничего из этого нет — медленное покачивание. На iPhone гироскоп включается
  кнопкой «Включить наклон» (так требует система).
- При системной настройке «уменьшить движение» всё стоит на месте.
- QR-код собирается при сборке как SVG (`src/lib/qr.ts`).
- Кнопка «Сохранить контакт» отдаёт файл `contact.vcf`, он собирается из `src/data/profile.ts`.
- Шрифты Unbounded, Onest и Martian Mono лежат в `src/assets/fonts` (латиница и кириллица
  отдельными файлами), с внешних серверов ничего не грузится.
